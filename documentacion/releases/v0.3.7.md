# v0.3.7 — Complejidad formal y control de regresiones

## Issue #40
- Análisis AST de complejidad ciclomática y cognitiva por función, callback, método y clase.
- API oficial de compatibilidad TypeScript 6 aislada para las métricas; el compilador, el build y el typecheck de la aplicación permanecen en TypeScript 7.
- Línea base reproducible de v0.3.6 con presupuestos exactos para máximos y número de funciones sobre las señales históricas.
- CI bloquea aumentos respecto a la línea base y valida que el artefacto publicado sea JSON válido.
- Pruebas unitarias del analizador y documentación de la definición, los límites y el criterio de regresión.

## Línea base
- 15 archivos, 160 funciones y 3 clases analizadas.
- Complejidad ciclomática máxima: 18.
- Complejidad cognitiva máxima: 21.
- 4 funciones con complejidad ciclomática superior a 10.
- 1 función con complejidad cognitiva superior a 15.

Los totales son diagnósticos. CI solo bloquea una regresión respecto a estos valores; no presupone que una función sea incorrecta por superar una señal.

## Validación
- Build y typecheck de frontend y Worker.
- 22 pruebas Node y validación del esquema Python.
- QA visual automatizado en Chromium.
- Auditoría npm de severidad alta sin vulnerabilidades.
- Build de Cloudflare validado antes de promover la release.
